Sliding Window

Easy

Learning Progress : 40%

Pattern Overview

The Sliding Window pattern is used whenever a problem involves a contiguous subarray or substring. Instead of recomputing every possible range, the window expands and shrinks efficiently, reducing the overall complexity from O(n²) to O(n).

Time Complexity

O(n)

Space Complexity

O(1)

Best Used When

  • Contiguous arrays
  • Substring problems
  • Longest / Shortest window
  • Maximum / Minimum sum
  • Fixed or Variable window

Pattern Recognition Checklist

  • ✅ Is the array contiguous?
  • ✅ Can two pointers solve the problem?
  • ✅ Can the window expand?
  • ✅ Can the window shrink?
  • ✅ Is the brute force solution O(n²)?

Common Mistakes

  • Updating the answer before shrinking the window.
  • Moving the left pointer too early.
  • Forgetting to remove elements from the frequency map.
  • Not handling duplicate characters correctly.

Algorithm Steps

  1. Initialize left and right pointers.
  2. Expand the right pointer.
  3. Update current window information.
  4. Check whether the window satisfies the condition.
  5. Shrink the left pointer whenever necessary.
  6. Update the final answer.

Dry Run Example 


Array = [1,2,3,4,5]

Window Size = 3

[1 2 3] → Sum = 6

↓

[2 3 4] → Sum = 9

↓

[3 4 5] → Sum = 12

Reusable Code Template 


int left = 0;

for(int right = 0; right < n; right++){

    // Expand Window

    while(condition){

        // Shrink Window

        left++;

    }

}
