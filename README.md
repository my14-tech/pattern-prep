🧠 Pattern Prep

A coding practice platform designed to help users learn and master Data Structures & Algorithms (DSA) patterns efficiently.

🚀 Features
    📚 Practice DSA pattern-based questions
    📊 Track progress
    🔐 User authentication (login/register)
    🧩 Organized problems by pattern
    ⚡ Fast and interactive UI

🛠️ Tech Stack
    Frontend: HTML, CSS, JavaScript
    Backend: Node.js / Python 
    Database: MongoDB / SQLite etc.
